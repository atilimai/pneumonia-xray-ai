# Demo Scope and Limitations

This document defines the functional boundaries and ethical limitations of the Pneumonia Detection AI demonstration application. These constraints are enforced to ensure system stability and to clarify the academic nature of this project.

## 1. Functional Constraints (Deployment Scope)
* **Single Image Processing:** The demo interface will only accept and process one X-ray image at a time.
* **No Batch Processing:** Uploading multiple images simultaneously (batch processing) or processing entire directories is strictly disabled.
* **Reasoning:** Lightweight deployment environments have strict RAM and CPU limitations. Restricting inference to a single image prevents server crashes and `Out of Memory (OOM)` errors during public demonstrations.

## 2. Ethical and Medical Disclaimer (Strictly No Clinical Claims)
* **Academic & Research Purposes Only:** This AI model and its accompanying web interface are developed strictly for academic, educational, and algorithmic demonstration purposes.
* **Not a Medical Device:** This system is **NOT** FDA-approved or CE-marked. It is not designed, intended, or authorized to diagnose, treat, cure, or prevent any medical condition (including pneumonia).
* **No Clinical Claims:** Any prediction or Grad-CAM heatmap generated by this demo must not be used as clinical evidence or a substitute for professional medical advice. Always consult a certified radiologist or healthcare provider for medical diagnoses.
